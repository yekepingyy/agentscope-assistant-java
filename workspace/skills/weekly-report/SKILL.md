# 周报技能

写周报时必须使用以下结构，不要自由发挥章节名：

1. **本周进展**（3～5 条，每条一句话）
2. **风险与阻塞**（没有就写「无」）
3. **下周计划**（2～4 条）
4. **需要协同**（点名角色/部门，没有就写「无」）

约束：
- 全文不超过 400 字
- 用条目，不用长段落
- 不要出现「好的」「我来帮你」等客套
- 落盘路径约定：`reports/weekly-YYYYMMDD.md`（日期用当天）
